## 🚀 Lancer le projet

Après avoir placé vos images :
```bash
npm run dev
```

Le site chargera automatiquement toutes vos images !

## ❓ En cas d'erreur

Si une image ne charge pas, vérifiez :
1. Le nom du fichier est exact (copier-coller depuis ce document)
2. L'extension est correcte (.jpg ou .png)
3. Le fichier est bien dans `src/imports/VTelephone4/`
